# 一枝红杏订阅使用步骤

1. 访问 [一枝红杏官网](https://order.yizhihongxing.club/)。
2. 阅读套餐说明、服务条款和退款规则。
3. 选择符合流量与设备需求的套餐并完成付款。
4. 登录用户中心，在“我的订阅”中获取订阅信息。
5. 按官网教程选择兼容客户端，添加订阅并更新配置。
6. 如遇到账户或订阅问题，通过官网工单联系服务方。

## 安全提醒

- 不要把订阅链接、账号密码或付款凭据提交到 GitHub Issue。
- 仅从客户端官方渠道获取软件。
- 不要安装来源不明的配置文件或证书。
- 客户端界面和订阅导入方式可能因版本不同而变化，请以官方教程为准。
